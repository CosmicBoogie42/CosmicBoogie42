## 🧭 For hiring managers

Hiring is a product too, so let's treat it like one. When we kick off a search, the things that help most are:

- [ ] The problem this person will solve in their first year
- [ ] What "great" looks like (and what's a nice-to-have)
- [ ] Who's in the interview loop, and what each round tests
- [ ] A decision timeline we can stick to

Bring those and we'll move fast. 🚀
